## 交付内容

代码文件包含前后端源码、测试、数据库初始化脚本、模拟元数据与微调种子、设计文档及pen原型。测试截图目录包含7张已有测试原图，明确区分真实模型、历史规则模拟模型及API夹具。

不包含已安装依赖、实际密钥、真实.env、数据库或运行日志；依赖声明和锁文件保留，安装后运行。所有业务样例数据均为模拟数据。
